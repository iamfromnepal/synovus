SCSS Architecture

Clean separation between _variables.scss, _custom.scss, and main.scss. Pre-configured with Dart Sass and quiet-deps support.

Bootstrap 5 Integration

Raw HTML5 & Modern JS

Ready to Build Your UI

Run the watcher script to compile your SCSS in real-time as you develop. Any changes in assets/scss/ will automatically reflect in assets/css/main.css.

$ npm run dev
// Watches and compiles SCSS automatically on every save
$ npm run build:css
// Builds production CSS bundle
Active File Locations
  • custom-overrides.scss: Customize theme colors, typography, border-radii, and custom components.
  • scss/bootstrap/: Full Bootstrap 5 SCSS source files ready for granular imports.
  • style.css: Main compiled stylesheet located at the project root.
