Architectural Mechanisms Explained

Multi-Template Scanning

PurgeCSS uses a universal word-boundary regex extractor: /[\w-/:]+(?. It extracts every CSS class token regardless of embedded PHP tags, Blade syntax, or ASP.NET Razor directives:

// Scans all templates automatically content: [ './**/*.{html,php,xhtml,shtml,cshtml,js}', '!./node_modules/**', '!./vendor/**' ]

Bootstrap Safelist Matrix

Dynamic classes added at runtime by JavaScript are preserved via regex safelisting so interactive components never lose animations:

safelist: { standard: [ /show$/, /collapsing$/, /fade$/, /active$/, /^modal-/, /^offcanvas-/ ], deep: [/^tooltip/, /^popover/] }

Payload Optimization

By dropping unneeded components and compressing selectors in-memory, network transfer size is drastically minimized:
