Branch Separation

Styles are modularly separated into custom token overrides (custom-overrides.scss) and local Bootstrap modules (scss/bootstrap/). Bootstrap's !default flags guarantee that your variables take precedence.

In-Memory Pipeline

Instead of compiling SCSS to disk and then invoking a separate CLI tool to purge it, build.js buffers CSS in Node RAM. Dart Sass + PurgeCSS execute end-to-end in ~150ms without any disk bottle-necks.

Any Template Extension

Whether your application serves static HTML, dynamic PHP with embedded server logic, or Razor CSHTML, the regex token extractor scans the code as raw tokens and protects every class you use.
